# Leads Tracker Chrome Extension

A lightweight Chrome Extension built with JavaScript that lets users save custom links and the currently active browser tab for quick access later.

## Features

- Save links manually
- Save the current browser tab
- Store data using Local Storage
- Delete all saved leads with a double-click
- Data persists even after closing the browser
- Render clickable links

## Technologies Used

- HTML
- CSS
- JavaScript
- Chrome Extension API
- Local Storage

## Installation

1. Clone the repository

```bash
git clone https://github.com/maryam-dev26/lead-tracker-extension.git
```

2. Open Chrome and go to:

```
chrome://extensions
```

3. Enable **Developer Mode**

4. Click **Load unpacked**

5. Select the project folder
